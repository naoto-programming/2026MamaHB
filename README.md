# 一か八か・リベンジ

1 と 8、最後に多く出るのはどっちだ。1台の端末をみんなで回して遊ぶ、サイコロとカードのパーティーゲームです（2〜6人）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要）。

1. 全員に目的の数（1 か 8）が半数ずつ割り当てられ、手札が5枚配られます
2. 自分の手番で手札から2枚出します。確率を動かす・サイコロを増やす・ポイント系カードを場に置く、など
3. 全員が3回ずつ手番を終えたらサイコロを全部振り、全体イベント → 役 → 場のポイント系カードの順に判定します
4. これを3ラウンド。サイコロ・手札・場のカード・全体イベントは次のラウンドに持ち越し、場のポイント系カードは毎ラウンド判定されます

## ファイル

| ファイル | 内容 |
|---|---|
| `js/config.js` | ルールの数値とカードの強さ（`BALANCE`）。ここを変えるとカードの説明文も変わる |
| `js/cards.js` | カードの一覧と効果 |
| `js/yaku.js` | 役（サイコロの並び）の一覧 |
| `js/events.js` | 全体イベントの一覧 |
| `js/state.js` | ゲームの状態と共通の関数 |
| `js/render.js` | 画面の描画 |
| `js/game.js` | 手番・ラウンド・判定の進行 |
| `css/style.css` | 見た目 |

`js/` のファイルは `index.html` に書いた順に読み込む必要があります（設定 → 状態 → カード → 役 → 全体イベント → 描画 → 進行）。
